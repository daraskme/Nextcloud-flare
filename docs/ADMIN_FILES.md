# 管理者による全利用者のファイル閲覧

管理者（`app_admin`）はサイドバーの **全利用者のファイル** から `/admin/files` を開き、利用者を選択して、その個人スペースのフォルダーとファイルを閲覧できます。

## 使い方

1. 管理者でログインして **全利用者のファイル** を開く。
2. **利用者** を選び、フォルダー名から目的の場所へ移動する。
3. **プレビュー** で内容を表示する。音声・動画は画面内のプレイヤー、画像・PDFなどは別タブで開く。ブラウザーが安全に表示できない形式はダウンロードになる。
4. **ダウンロード** でファイルを保存する。
5. 同じ画面の **閲覧履歴** で所有者・閲覧者・ファイル ID・操作・時刻を確認する。

一覧はページ単位で取得します。所有者表示を確認してから操作してください。削除済みファイルと無効な利用者の内容にはアクセスできません。

## 権限と履歴

- 管理画面は読み取り専用です。他人のファイルの編集・削除・移動・共有変更は提供しません。
- 通常の「ファイル」画面、WebDAV、一般利用者の API は既存の所有者・共有権限を使います。
- 管理者用 API は現在有効な Access セッションと管理者ロールを要求します。アプリパスワードでは利用できません。
- プレビューとダウンロードは対象ファイルを一つに限定した短期 ticket と content-origin Cookie を使います。発行・受取・配信時に現在の権限を検査します。
- 一覧・ファイル情報の取得、閲覧 ticket の発行、内容へのアクセスを記録します。履歴はアクセスの記録であり、ファイル全体を受信したことや、利用者が目で見たことの証明ではありません。動画の分割取得などで複数行になる場合があります。
- 監査記録を書き込めない場合は内容を配信しません。履歴には秘密値やファイル内容を保存しません。

## ステージング確認

管理者で他の利用者の小さいテストファイルを一覧・プレビュー・ダウンロードし、所有者と保存した内容が一致することを確認します。一般利用者の別ブラウザープロファイルでは管理メニューがなく、`/admin/files` を直接開いても利用できないことを確認します。

音声・動画は再生開始、途中へのシーク、再開を確認してください。再生可能な形式はブラウザーの codec 対応に依存します。アプリはこの経路で自動変換を行いません。
